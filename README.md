# Gold & Oil Power BI Dashboard

An interactive Power BI project for analyzing gold and oil market data.

## Project files

- `BIProject_final2.pbix` — Power BI dashboard
- `Gold_Oil_Dashboard_Presentation.pptx` — project presentation
- `BI-61s.OIL&GOLD.docx` — project report
- `Data API.pdf` — data API documentation
- `Read me dashboard-61s.docx` — dashboard guide
- `Read me report-61s.docx` — report guide

## Tools

- Microsoft Power BI
- Market data APIs
- Microsoft PowerPoint and Word

## Usage

Open `BIProject_final2.pbix` in Power BI Desktop to explore the dashboard.
